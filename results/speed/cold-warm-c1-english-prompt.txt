Range: decode 53.8-63.2 tok/s, acceptance 57.3-68.6 %.

WHY THIS FILE EXISTS. Our published cold/warm C1 numbers (43-47 tok/s,
acceptance 44-48 %) were measured with the SAME task written as a Turkish
prompt. The script published in this repository asks for the same LRU cache in
English, and on the identical engine that measures 10-15 tok/s faster with
about 13 points more speculative acceptance.

Nothing about the engine changed between the two sets. The difference is the
prompt language: the DFlash2 drafter predicts English continuations
considerably better than Turkish ones. We did not investigate further and we
have not repeated the whole speed battery in English, so the tables elsewhere
in this repository still carry the Turkish-prompt numbers. Treat that as a
floor for English workloads rather than as a ceiling.

The "cold" run above is not genuinely cold: the engine had been serving for
some time. A true cold first request after an engine start is slower — see the
post-reboot figures in audit/README.md.
